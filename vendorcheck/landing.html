FAQ

Questions finance teams ask.

Where does the data come from?

Company, people and news data from Crustdata, the company's own website, public pages that state registry numbers, and your own records: vendor master, purchase orders and goods receipts.

Does it check the company registry?

India's MCA registry has no public API and its portal uses a CAPTCHA, which we do not bypass. When no fetchable page confirms a registry number, the case says "registry not confirmed" instead of claiming it.

Can it pay the wrong account?

It pays only the account verified when the vendor was onboarded. A different account on an invoice, or a change request by email, holds the payment until a person confirms by calling the number already on file.

What happens if it crashes mid-payment?

On restart it finishes any payment that was approved but not yet made, once. The payment ledger cannot hold two rows for the same invoice.

Does it use AI to decide?

No model makes the decision. Each check is a rule over sourced facts, so the same request always gets the same answer and every answer can be explained.
