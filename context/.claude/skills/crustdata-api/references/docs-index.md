# Crustdata docs index

Every public docs page, grouped as in https://static-assets.crustdata.com/llms.txt (recruiting-app pages omitted). Each URL returns clean markdown:

```bash
curl -sL https://docs.crustdata.com/person-docs/search/reference.md
```

- Pages marked **(login)** redirect to `app.crustdata.com` sign-in (live/enterprise endpoints). Their schemas are not public, so check `GET /account/endpoints` to see whether you have access.
- Everything public in one file (~1.6 MB, too big to read whole, so grep it): `https://docs.crustdata.com/llms-full.txt`. Pages in it start with `# <Title>` followed by `Source: <url>`.
- For a field or operator question, the area's **reference** page is the authority. Introduction pages hold worked examples.
