#### Why Track 6 Wins ContextCon 05

1. **Maximized Rubric Alignment (20 pts for Robustness/Idempotency + 25 pts for Execution)**
   The judging rubric specifically allocates 20 points to "Robustness/idempotency/crash restart/approval gates" and 20 points to "Customer value (real paid outcome)." Track 6 is the only track where idempotency is the core product requirement rather than an auxiliary feature. You can run a terminal demo that kills the process midway through a 100-invoice batch, restarts it, and proves that every invoice is paid exactly once without double-debiting.
2. **Deterministic Defense Against Hidden Tests**
   The hidden test cases feature duplicate records, lookalike names, and unverifiable questions. Track 6 handles these through pure Python deterministic checks:
   - *Duplicate Records*: Sha256 hash of invoice fields (vendor + amount + invoice number) catches duplicates instantly.
   - *Lookalike Names*: Levenshtein distance on vendor names and domain match checks (e.g. `delhivry-freight.in` vs `delhivery.com` via Crustdata enrich) immediately route to HOLD.
   - *Unverifiable Details*: When a bank account update request lacks verified board/exec signatures in Crustdata, the agent returns an explicit `cannot verify authenticity: bank change HOLD` rather than hallucinating approval.
3. **Historical Winner Precedent (The PayeeGuard Blueprint)**
   ContextCon 03's standout project was PayeeGuard, which tackled this exact problem space using Crustdata's identity graph and deterministic Python gates. Crustdata judges know and reward this architecture.
4. **Concrete Indian 3PL Unit Economics**
   An Indian 3PL operating 500+ regional trucks and 20 distribution hubs processes ~15,000 carrier freight bills monthly. Carrier billing fraud and duplicate billing represent 1-2% of total freight disbursements.
   - *Buyer*: Chief Financial Officer / Financial Controller at the 3PL.
   - *Pricing*: ₹60 per processed invoice + ₹1,500 bounty per detected fraudulent billing attempt.
   - *Cost per run*: ~₹0.40 in LLM extraction + Crustdata API query, providing a 99% gross margin.

#### Top Risk and How to Mitigate It in the Remaining 4.5 Hours

- **The Top Risk: LLM Decision Hallucination & Prompt Injection Vulnerability**
